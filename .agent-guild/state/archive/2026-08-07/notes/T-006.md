## The commit split, and why it falls this way

**Four commits, not one and not six.** The seams follow what could be reverted
independently, which is a stricter test than "which task produced it."

1. **`tests/apps.bats` first.** Required to be separate, and it belongs first on its
   own merit: it's the commit that makes `bats tests/` terminate. Put anywhere else in
   the series, every commit before it sits on a suite that hangs, which makes the
   history unbisectable for the exact bug the rest of the series is about. Its why is
   also a different why: a harness PATH leak that let a case removing its own stub
   resolve the real binary. The only thing it shares with #17 is the date fzf was
   installed, and the message says so explicitly so nobody later reads it as part of
   the conversion.

2. **The four scripts plus `tests/install-failures.bats` together.** I considered
   splitting per script. Rejected: they're one behavior contract applied at four
   sites, and a commit converting one installer while the other three still swallow
   their failures is a half-state nobody would want to land on. The tests go in with
   them rather than after, because `install-failures.bats` asserts against converted
   scripts and fails on its own at the previous commit. A test commit that's red until
   the next commit isn't independently sensible, which is the bar here.

3. **`tests/doctor.bats` separate.** This is the call I went back and forth on, since
   it's part of the same issue. It's separate because it tests a *different program*.
   `dotfiles-doctor` is byte-identical before and after this job; the case covers
   behavior that predates all of it. If the conversion ever gets reverted, this test
   should survive that revert, and it can only survive if it isn't inside the same
   commit.

4. **Working memory separate.** Six precedents in this repo's own history put
   `docs(memory):` in its own commit (`ade9399`, `c03107d`, `3e2e10d`, `5bf3563`,
   `735e7b1`, `91f8812`), so folding it into the code commit would have been the
   novel choice. It's last because `conventions.md` now cites
   `tests/install-failures.bats`, which only exists from commit 2 onward.
