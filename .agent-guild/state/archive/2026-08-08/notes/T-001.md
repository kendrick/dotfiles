## Judgment calls / things worth flagging

- **Placement of `load 'helpers'`**: the spec said "at the top... above any
  `setup()`" without pinning it precisely relative to each file's leading
  comment block. I put it after the header comment and before the file's
  variable declarations (`SRC=`, `SCRIPT=`, etc.), which is where
  `install-failures.bats` naturally wanted it too (right where its local
  helper definitions used to sit, structurally). This is consistent across
  all seven files. If a checker expected `load` to precede even the header
  comment (i.e., as literally line 2 right after the shebang), that would be
  a different placement than what I did — I judged interrupting a file's
  opening explanatory comment with a `load` line to be worse style, and nothing
  in B-3 or B-1 constrains placement beyond "above any setup()", which this
  satisfies in all seven files.
- I did not touch `tests/lint.bats` or `tests/mutation-check.sh` — neither
  exists yet, and B-3's check_method explicitly says `tests/lint.bats` (a
  later task) need only load the helpers if it uses them.
- No assertion call sites were converted anywhere, per the constraint in the
  spec excerpt; that work belongs to T-002 through T-005.
