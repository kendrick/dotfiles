## The disjunction (baseline line 244)

`[[ "$output" == *"undeclared"* || "$output" == *"casks"* ]]` in "a half with no casks key
at all is reported as undeclared" became:

```bash
case "$output" in
*undeclared* | *casks*) ;;
*) return 1 ;;
esac
```

Built directly from `case`, not from two `assert_contains` calls, per the task's explicit
instruction — this keeps `tests/mutation-check.sh`'s site count at 20 for this file rather
than 21, and avoids leaving the script's polarity-swap and sentinel-needle mutation rules
both plausibly matching the same site. Both substrings (`undeclared` and `casks`) survive
in the pattern; neither arm was dropped. Added a one-line comment above it explaining why
this site is hand-built rather than helper-based (the helpers only take one needle, and
`case` is what propagates correctly under bash 3.2 errexit) — matching the register the
constitution (D-2) asks for, why not what.

Did not touch `dot_local/bin/executable_dotfiles-doctor` or any other test file.
