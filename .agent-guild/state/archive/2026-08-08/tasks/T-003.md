## Spec excerpt

Convert all 12 bare `[[ ]]` assertions in `tests/font.bats`. Two of them do not assert against `$output` and need the helper's two-argument form; one of those is the single most interesting site in the whole job.

**Why.** Under bash 3.2 — the shell bats runs test bodies under — a failing `[[ ]]` inside a function is silently discarded unless it is the function's last statement. `grep` and `case`, which the helpers use, propagate correctly from any position, including inside a loop.

**The helpers**, built by T-001 in `tests/helpers.bash` and loaded by this file:

- `assert_contains "needle"` — asserts against `$output`
- `assert_contains "needle" "$haystack"` — explicit haystack, needed where the subject is not `$output`
- `assert_not_contains` in both forms

All line numbers below are baseline (`61213fe`) and are **now +2 in the working tree**, since T-001 added a `load` line above them. Locate each site by its text rather than jumping to the number.

**The two computed-haystack sites.** Both need the second argument; dropping it silently re-points the assertion at `$output`, which is a different and almost certainly passing test:

```bash
# :500 baseline
[[ "$(jq -r '.monolisa.editor.ligatures' "$HOME/.config/font/registry.json")" == *"dlig"* ]]
# becomes
assert_contains "dlig" "$(jq -r '.monolisa.editor.ligatures' "$HOME/.config/font/registry.json")"

# :554 baseline
[[ "$terminal_family" == *"$fallback"* ]]
# becomes
assert_contains "$fallback" "$terminal_family"
```

**Line 554 is why this job exists**, and it is worth understanding before you touch it. It sits as the last statement of a `for` body iterating every key in the font registry:

```bash
for key in $(keys_in_order); do
	fallback=$(jq -r ... )
	[ -n "$fallback" ] || continue
	terminal_family=$(jq -r ... )
	[[ "$terminal_family" == *"$fallback"* ]]
done
```

Nothing follows it inside its block, so by the issue's own definition of a "vulnerable position" it looks safe. It is not. Measured on this machine: with `[[ ]]`, a failing early iteration followed by any passing later iteration yields exit 0 and a green test — so any font whose fallback is missing is masked by any font whose fallback is present. With the helper, the first failing iteration aborts. This one conversion is the difference between that case testing every key and testing only the last one.

Leave the `[ -n "$fallback" ] || continue` on the line above alone. It is single-bracket control flow, measured safe, and it is the idiom `tests/packages.bats:146` is being converted *to* in T-005.

**Do not** change what any assertion checks, delete or retitle a case, or touch `dot_local/bin/executable_dotfiles-font` or the registry fixtures. `tests/font.bats` must still report 44 cases and pass. This is the slowest file in the suite at roughly 12 seconds, so expect the run to take a moment.

**Verify before reporting done.**
