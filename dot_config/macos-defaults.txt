# macOS defaults the daily sync captures into macos-defaults.captured.
# Format: domain key type, one per line. type is bool, int, float, or string.
# This is an allowlist on purpose: a key two machines legitimately disagree on
# (display or locale settings, say) would trade values on every sync, each machine
# overwriting the other's capture.
#
# Deliberately left off, and why:
#   com.apple.dock autohide                depends on the attached display
#   com.apple.screencapture location       a $HOME path
#   AppleLanguages, AppleLocale,
#   AppleMeasurementUnits, AppleMetricUnits  per-user locale
#   com.apple.finder FXInfoPanesExpanded   a dict, not a scalar
#   com.apple.Safari keys                  sandboxed, unreadable without Full Disk Access
